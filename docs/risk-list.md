## 2. 安全与隐私

| # | 风险 | 影响 | 缓解措施 | 状态 |
|---|---|---|---|---|
| S1 | AES-GCM 密钥泄露或丢失 | 密文不可恢复 / 数据泄露 | 密钥仅走环境变量、不进仓库；阶段 6 备份方案含密钥托管说明；轮换方案开放（V2 密钥版本列） | 进行中 |
| S2 | JWT / 刷新令牌被盗用 | 冒用身份 | 刷新令牌轮换 + 存 SHA-256 哈希 + 可撤销；访问令牌短有效期（1.2 定） | 进行中 |
| S3 | 匿名量表接口被刷 / 恶意建工单 | 工单噪声、资源浪费 | RateLimiter 全站 + 匿名提交限流；工单 10 分钟去重（crisis-flow §3） | 已缓解 |
| S4 | Discourse 回调被伪造 | 假预警 | 回调 HMAC 签名校验（共享密钥走环境变量） | 已缓解 |
| S5 | SQL 注入 | 数据泄露 | Dapper 全参数化；禁止字符串拼接 SQL（代码审查项） | 已缓解 |
| S6 | 日志泄露敏感明文 | 隐私事故 | 日志脱敏中间件 + Serilog 排除密文字段；阶段 1 起自查表固定检查"日志无明文" | 进行中 |
| S7 | 管理端弱口令 | 后台失守 | 初始管理员由部署脚本生成强随机密码并强制首登修改；管理端可加 IP 白名单（部署层，开放） | 进行中 |

## 3. 技术与实现

| # | 风险 | 影响 | 缓解措施 | 状态 |
|---|---|---|---|---|
| T1 | MySQL 5.7 不强制 CHECK 约束 | 脏数据入库 | 应用层 FluentValidation 全量校验；升级 8 后约束自动生效 | 已缓解 |
| T2 | 5.7 无 CTE / 窗口函数 | 复杂查询受限 | SQL 以 5.7 为基线编写；趋势统计用简单聚合 + 应用层组装 | 已缓解 |
| T3 | Discourse 官方镜像资源占用高（内存 ~2GB+） | 部署机配置不足 | 阶段 3 前确认部署机规格；必要时单独主机部署社区 | 开放 |
| T4 | AI 模型 API 成本 / 超时 / 内容安全 | 体验与预算 | 会话限流 + 消息长度上限；超时降级话术；成本预估在阶段 5 前输出 | 开放 |
| T5 | 时区处理不一致（DB UTC vs 用户本地日） | 日记归属日期错乱 | DB 全 UTC；`entry_date` 由前端按本地日提交，服务端不做时区换算（约定记录在 api-spec） | 已缓解 |
| T6 | 防超卖唯一索引在极端并发下的死锁 | 预约失败体验 | 事务短小 + 时段行原子更新；阶段 4 并发测试覆盖 | 进行中 |
| T7 | 临时验证环境（5.7 临时实例）与开发库配置漂移 | 迁移在真实库失败 | 1.2 迁移工具在**开发库**首次运行即为准；开发库 = 本机 5.7.44 服务 | 已缓解 |
